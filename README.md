# Задачник

Небольшое веб-приложение для управления личными задачами на Django. У каждого пользователя свой аккаунт, свои задачи и свои категории. Учебный проект.

## Возможности

- Регистрация, вход и выход (стандартная аутентификация Django)
- Создание, просмотр, редактирование и удаление задач
- Отметка задачи выполненной
- Категории задач
- Фильтры: все / активные / выполненные
- Срок выполнения, просроченные задачи выделяются
- Пользователь видит и меняет только свои задачи
- Админ-панель Django
- Адаптивный интерфейс в стиле Apple, тёмная тема

## Стек

Python 3, Django, SQLite, Django Templates, HTML, CSS.

## Запуск проекта

Нужен установленный Python 3 (при установке отметьте «Add Python to PATH»).

```powershell
git clone https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
cd ИМЯ_РЕПОЗИТОРИЯ
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000/

Если PowerShell блокирует активацию окружения, выполните:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Для macOS и Linux активация окружения: `source venv/bin/activate`.

## Страницы

| Адрес | Назначение |
|-------|-----------|
| `/` | Перенаправление на вход или список задач |
| `/register/` | Регистрация |
| `/login/` | Вход |
| `/tasks/` | Список задач |
| `/tasks/new/` | Новая задача |
| `/tasks/<id>/` | Просмотр задачи |
| `/admin/` | Админ-панель |

## Тесты

## Структура

```text
config/       настройки проекта и корневые маршруты
tasks/        приложение: модели, формы, views, тесты
templates/    HTML-шаблоны
static/       CSS и JS
```

## Безопасность

- Пароли хранятся стандартными средствами Django
- Защита от CSRF включена
- Все запросы к задачам фильтруются по владельцу, чужая задача возвращает 404
- Выход, удаление и смена статуса выполняются только через POST
